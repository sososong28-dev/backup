# 旺店通 RPA 导出清单

建议先让 RPA 每天固定导出这些文件到 `exports/inbox/`：

1. 商品/货品档案
   - 文件名建议：`商品档案_yyyyMMdd.xlsx`
   - 用途：建立 SKU、商品名称、规格、条码、品牌、分类。

2. 订单或销售订单
   - 文件名建议：`销售订单_yyyyMMdd.xlsx`
   - 用途：建立订单主表和每日销售金额。

3. 订单明细或销售明细
   - 文件名建议：`销售明细_yyyyMMdd.xlsx`
   - 用途：建立每个 SKU 的销量、金额、折扣。

4. 库存明细
   - 文件名建议：`库存明细_yyyyMMdd.xlsx`
   - 用途：建立每日库存快照。

5. 售后/退款
   - 文件名建议：`售后退款_yyyyMMdd.xlsx`
   - 用途：建立退款金额、退款原因、售后状态。

RPA 动作建议：

- 每个报表用固定筛选条件和固定文件名格式。
- 导出前先清空浏览器下载目录，导出后再移动到本项目 `exports/inbox/`。
- 如果旺店通导出列可以自定义，尽量保留订单号、店铺、商品编码、商品名称、规格、数量、金额、时间这些字段。
- 每次导出后运行 `scripts/run_daily_import.ps1`，成功后文件会进入 `exports/archive/`，失败文件会进入 `exports/error/`。
